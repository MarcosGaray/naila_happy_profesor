# Registro de Sesiones con IA 🤖📝

Esta carpeta almacena el historial cronológico de todas las sesiones de trabajo con Inteligencia Artificial en el proyecto **Happy Profesor**.

## Convención de Nombres
Los archivos deben nombrarse siguiendo el formato:
`NNN_descripcion_breve.md` (ejemplo: `001_3d_experience_setup.md`).

## Estructura Recomendada
Utilizar el formato definido en [template_session.md](template_session.md) para cada nueva sesión.
